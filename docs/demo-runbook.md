# AEGIS demo runbook

Assumes AEGIS installed with `AEGIS-1.0.0-Setup.exe` to the default `C:\Program Files\AEGIS`; adjust the path if you chose another folder.

## 0. Before the recording

1. Use a **disposable** USB stick, 1–32 GB. Its data will be destroyed in Part B. Copy a few photos, PDFs and documents onto it, then delete some of them in Explorer (Shift+Delete) so Recovery has deleted files to find.
2. Close any program that has files open on the stick.
3. Start AEGIS **elevated**: use the **AEGIS (Administrator)** Start-menu shortcut (or right-click `C:\Program Files\AEGIS\AEGIS.exe` → *Run as administrator*). Raw device reads and writes need elevation. Without it, Disk Imager and Sanitization say *REQUIRES PRIVILEGE*, which is accurate.

```powershell
Start-Process -Verb RunAs -FilePath 'C:\Program Files\AEGIS\AEGIS.exe'
```

The bundled Java 17 runtime is used automatically (`jre\`). The AEGIS engine lives in `aegis-engine\` and starts on demand; nothing has to be started by hand.

**Never point any sanitization at an internal drive.** AEGIS refuses internal SSD, NVMe, SATA and HDD drives in the engine itself. Only removable USB or SD media are eligible.

## Part B — the disposable USB (destructive; elevated AEGIS only)

1. Plug in the disposable stick. Go to **Disk Imager → Refresh Devices**. The stick appears with its real model, serial, capacity, filesystem and mount. The internal drive shows *SYSTEM DISK* and cannot be selected.
2. Select the stick → Preflight (elevated, not system, identity bound, destination space and destination not on the source) → Device Identity → Case & Evidence → E01 → **Start Acquisition**. The engine binds the serial and size to the open read handle.
3. Verification → **Add Image to Case** → **Advanced Recovery** (button on the Complete step) → Start Scan. The deleted files you prepared are recovered.
4. **Sanitization → Physical Device → Refresh**. The stick shows *Eligible for Sanitization*. The capability panel lists what the engine probed: firmware methods are usually unavailable through USB bridges, and the whole-drive Clear is *READY AFTER PREPARE* while volumes are mounted.
5. Choose **Zero-fill overwrite — single pass (Clear)**, or the legacy DoD profile. Leave Deep Forensic Purge on.
6. **Sanitize Device…**. In the authorization dialog: choose the verified acquisition from step 2 as the backup, tick the acknowledgement, and type the serial exactly. **Authorize & Sanitize**.
7. AEGIS takes the disk offline (not persistent), the engine re-reads and binds the identity, then writes. A changed identity aborts. Watch the live progress and log, then the read-back verification result and the outcome achieved (Clear).
8. Reports → the device sanitization report → **Verify Signature & Chain**. Audit Trail → **Verify Audit Chain**.
9. Replug the stick to bring it back online.

**Scripted alternative for Part B**, from an elevated PowerShell with the disposable stick attached. It prompts for the serial and `SANITIZE` before writing:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\usb-demo-test.ps1
```

## Recovery from a problem during the demo

| Symptom | Meaning | Action |
|---|---|---|
| *REQUIRES PRIVILEGE* | AEGIS is not elevated | Restart AEGIS with Run as administrator |
| *INTERNAL DRIVE — sanitization disabled* | Policy: internal drives are never sanitized | Expected; use a removable USB/SD device |
| `MountedRefused` / *READY AFTER PREPARE* | A volume on the stick is mounted | AEGIS takes the disk offline when authorized; close Explorer windows on the stick |
| `IdentityMismatch` / `DeviceVanished` | The stick was replugged or swapped | Refresh Devices and select it again; nothing was written |
| `E01NeedsWholeSectors` | The source is a file whose size is not a whole number of sectors | Choose RAW |
| Engine *Unavailable* on Home | `aegis-engine` is missing or damaged | Re-extract the AEGIS package |
